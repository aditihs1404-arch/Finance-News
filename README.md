# The 6:30 Brief

A five-minute daily market brief, ready by 6:30am Jakarta time (WIB).

- **Covers:** the previous US session, plus what it means for Japan, Korea, Taiwan and China that morning.
- **Sources:** CNBC and Yahoo Finance only.
- **Format:** at most five top stories ranked by impact and an earnings scorecard, and upcoming events in Jakarta time.
- **Schedule:** Monday to Saturday. Monday's edition is a weekend recap and week-ahead preview.

The latest brief is `index.html`, served by GitHub Pages. Each day's brief is archived in [`briefs/`](briefs/) as `YYYY-MM-DD.html`.

These summaries are for personal reading, not investment advice.
